# 📘 Clase 2: Manejo de Estados en React

En esta segunda clase nos adentramos en uno de los pilares fundamentales de React: el **manejo de estados**. Aprenderemos a utilizar `useState`, uno de los hooks más importantes, para construir interfaces dinámicas e interactivas.

## 🧠 Temas abordados

- ✅ Introducción a **props** en React
- ✅ ¿Qué son los **hooks** y por qué son importantes?
- ✅ Uso de `useState` para manejar el estado dentro de componentes funcionales
- ✅ Actualización de estado de forma eficiente
- ✅ Buenas prácticas al trabajar con arreglos en el estado

## 🚀 Objetivo de esta clase

Comprender cómo gestionar datos dinámicos dentro de una aplicación React utilizando el hook `useState`, y cómo la interacción del usuario puede modificar esos datos.

El objetico de esta clase es poder:

- Entender la diferencia entre props y estado
- Crear y actualizar estados con `useState`
- Implementar listas dinámicas que respondan a la interacción del usuario
- Manipular arreglos en el estado (agregar y eliminar elementos)

## 👨‍💻 Proyecto

Como práctica, se desarrolló una **lista de compras interactiva**, donde el usuario puede:

- Agregar productos a una lista
- Eliminar productos de la lista

Esta práctica refuerza el manejo del estado en componentes funcionales, especialmente el trabajo con arreglos.

### Crear el proyecto con Vite

```bash
npm create vite@latest lista-compras --template react
cd lista-compras
npm install
```
